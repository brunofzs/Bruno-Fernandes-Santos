# Portfólio — Bruno Fernandes

Site pessoal responsivo feito com HTML, CSS e JavaScript puro. Inclui:
- Layout adaptável para celular, tablet e computador
- Tema escuro e claro (preferência salva no navegador)
- Menu mobile
- Animações suaves ao rolar a página
- Seções sobre, projetos, habilidades, experiência e contato

## 1. Personalizar seus contatos

Abra `script.js` e preencha os dados no começo do arquivo:

```js
const PROFILE = {
  email: "seuemail@exemplo.com",
  github: "https://github.com/seuusuario",
  linkedin: "https://www.linkedin.com/in/seu-perfil/",
  instagram: "https://www.instagram.com/seuusuario/"
};
```

Não deixe links que não sejam seus. Se um campo ficar vazio, o respectivo link não será exibido.

## 2. Conferir no computador

Abra a pasta no VS Code. Você pode abrir `index.html` diretamente no navegador ou usar a extensão Live Server.

## 3. Publicar gratuitamente no GitHub Pages

1. Entre em https://github.com e faça login ou crie uma conta.
2. Clique em **New repository**.
3. Dê o nome `bruno-fernandes-portfolio` e deixe como **Public**.
4. Envie todos os arquivos desta pasta para a raiz do repositório (`index.html`, `style.css`, `script.js`, `favicon.svg` e `README.md`).
5. No repositório, abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
8. Aguarde a publicação. O GitHub mostrará o endereço público do site na própria página de Pages.

O endereço normalmente será `https://SEU-USUARIO.github.io/bruno-fernandes-portfolio/`.

## 4. Atualizar o site

Sempre que editar os arquivos, envie as alterações para o mesmo repositório. O GitHub Pages atualiza o site automaticamente após alguns instantes.

## Antes de publicar

Revise os textos e preencha os contatos. O conteúdo foi montado com base nas informações fornecidas nas conversas; atualize qualquer informação que tenha mudado.
